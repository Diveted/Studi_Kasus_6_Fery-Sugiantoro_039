# Sistem Pencatatan Nilai Mahasiswa

## Penjelasan Program

Program ini digunakan untuk mencatat dan menampilkan data nilai mahasiswa dengan menggunakan file JSON sebagai penyimpanan data.

### Bagian-bagian Program

- `import json` digunakan untuk membaca dan menyimpan data dalam format JSON.
- `import os` digunakan untuk membersihkan tampilan terminal.
- `bersihkan_layar()` digunakan untuk membersihkan layar ketika program selesai.
- `tampilkan_data()` digunakan untuk membaca dan menampilkan seluruh data mahasiswa dari `genshin.json`.
- `tambah_data()` digunakan untuk memasukkan data mahasiswa baru dan menyimpannya ke dalam file JSON.
- `data.append()` digunakan untuk menambahkan data baru ke dalam data yang sudah ada.
- `json.dump()` digunakan untuk menyimpan data yang telah diperbarui ke `genshin.json`.
- `while True` digunakan agar program terus berjalan sampai pengguna memilih keluar.
- `if`, `elif`, dan `else` digunakan untuk mengatur pilihan menu.

## File

- `genshin.py` : kode program Python.
- `genshin.json` : file penyimpanan data nilai mahasiswa.
